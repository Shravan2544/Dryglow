2. Drag all 3 files (index.html + 2 images) onto the page
3. Done! Your site is live instantly

## 📝 GOOGLE SHEETS SETUP (5 minutes)

### Quick Steps:
1. Create a Google Sheet with headers: `Name | Email | Phone | Timestamp`
2. Go to Extensions → Apps Script
3. Paste the code from SETUP-GUIDE.md
4. Deploy as Web App (Anyone can access)
5. Copy the URL and paste it in index.html (line ~950)
